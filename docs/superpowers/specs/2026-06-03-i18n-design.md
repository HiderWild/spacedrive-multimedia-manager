# i18n (Internationalization) Design Spec

> **Date:** 2026-06-03
> **Status:** Approved
> **Scope:** All platforms (Web, Desktop/Tauri, Mobile)

## Goal

Add multi-language support to Spacedrive with Chinese (zh) as the default language and English (en) as fallback. The system should be extensible for adding more languages later.

## Architecture

- **Library:** `react-i18next` + `i18next`
- **Translation ownership:** `packages/interface` (shared UI package)
- **Initialization:** Each app calls `initI18n()` with a platform-specific persistence adapter
- **Fallback:** English (`en`) — any missing Chinese key shows the English translation
- **Type safety:** Auto-generated TypeScript types from translation JSON files

## File Structure

```
packages/interface/src/
  i18n.ts                              — i18n initialization function
  i18n/
    types.d.ts                         — auto-generated type definitions
    react-i18next.d.ts                 — module augmentation for type-safe t()
    persistence.ts                     — LanguagePersistence interface
  locales/
    en/
      common.json                      — shared strings (buttons, actions, statuses, units)
      sidebar.json                     — sidebar navigation, groups, labels
      settings.json                    — settings page content
      dialog.json                      — modal/dialog text
      overview.json                    — overview/dashboard page
      explorer.json                    — file explorer view
      search.json                      — search functionality
      errors.json                      — backend error code translations
    zh/
      common.json
      sidebar.json
      settings.json
      dialog.json
      overview.json
      explorer.json
      search.json
      errors.json
  components/settings/
    LanguageSelector.tsx               — language switcher dropdown
  hooks/
    useErrorTranslation.ts             — maps backend error codes to translated strings
scripts/
  generate-i18n-types.ts               — generates types.d.ts from JSON files
```

## Initialization

### Core config (`packages/interface/src/i18n.ts`)

```ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import Backend from 'i18next-resources-to-backend';

interface InitI18nOptions {
  persistence: {
    getLanguage: () => string | null;
    setLanguage: (lang: string) => void;
  };
  defaultLanguage?: string; // defaults to 'zh'
}

export function initI18n(options: InitI18nOptions) {
  const savedLang = options.persistence.getLanguage();

  i18n
    .use(initReactI18next)
    .use(Backend((lang, ns) => import(`./locales/${lang}/${ns}.json`)))
    .init({
      lng: savedLang || options.defaultLanguage || 'zh',
      fallbackLng: 'en',
      defaultNS: 'common',
      ns: ['common', 'sidebar', 'settings', 'dialog', 'overview', 'explorer', 'search', 'errors'],
      interpolation: { escapeValue: false },
    });

  i18n.on('languageChanged', (lng) => {
    options.persistence.setLanguage(lng);
    document.documentElement.lang = lng;
  });

  return i18n;
}

export { i18n };
```

- Pattern: `section.key` or `section.subsection.key`
- Examples: `actions.save`, `navigation.overview`, `delete.confirmMessage`

## Language Switcher

Lives in Settings page under "General" section. Uses Radix `Select` component.

```tsx
import { useTranslation } from 'react-i18next';

const LANGUAGES = [
  { code: 'zh', label: '中文' },
  { code: 'en', label: 'English' },
];

export function LanguageSelector() {
  const { i18n, t } = useTranslation('settings');

  const handleChange = (lang: string) => {
    i18n.changeLanguage(lang);
  };

  return (
    <div>
      <label>{t('general.language')}</label>
      <Select value={i18n.language} onValueChange={handleChange}>
        <SelectTrigger>
          {LANGUAGES.find((l) => l.code === i18n.language)?.label}
        </SelectTrigger>
        <SelectContent>
          {LANGUAGES.map((lang) => (
            <SelectItem key={lang.code} value={lang.code}>
              {lang.label}
            </SelectItem>
          ))}
        </SelectContent>
      </Select>
    </div>
  );
}
```

## Backend Error Code Mapping

The Rust backend returns structured errors with a `code` field. The frontend maps these to translated strings.

**Backend error format:**
```rust
#[derive(Debug, Serialize)]
pub struct ApiError {
    pub code: String,      // e.g., "LOCATION_NOT_FOUND"
    pub message: String,   // English fallback for logging
}
```

**Error translation files (`en/errors.json`, `zh/errors.json`):**

```json
// zh/errors.json
{
  "LOCATION_NOT_FOUND": "未找到位置",
  "LOCATION_ALREADY_EXISTS": "位置已存在",
  "FILE_NOT_FOUND": "未找到文件",
  "LIBRARY_NOT_FOUND": "未找到资料库",
  "INSUFFICIENT_PERMISSIONS": "权限不足",
  "NETWORK_ERROR": "网络连接失败",
  "UNKNOWN": "发生未知错误"
}
```

**Usage hook:**
```ts
export function useErrorTranslation() {
  const { t } = useTranslation('errors');
  return (code: string, fallback?: string): string => {
    const translated = t(code);
    return translated !== code ? translated : fallback || code;
  };
}
```

## Type Safety

Auto-generated types from JSON files ensure compile-time checking of translation keys.

**Module augmentation (`i18n/react-i18next.d.ts`):**
```ts
import 'react-i18next';
import type { Resources } from './types';

declare module 'react-i18next' {
  interface CustomTypeOptions {
    resources: Resources;
  }
}
```

**Build script (`scripts/generate-i18n-types.ts`):**
Reads all `en/*.json` files and generates `i18n/types.d.ts`. Run before build via `bun run generate:i18n-types`.

## Phased Migration

| Phase | Scope | Namespaces |
|-------|-------|-----------|
| 1 (this plan) | Foundation + sidebar + common | `common`, `sidebar` |
| 2 | Core views | `overview`, `explorer`, `settings` |
| 3 | Dialogs & search | `dialog`, `search`, `errors` |
| 4 | Polish | Date/time formatting, pluralization, mobile strings |

**Migration rule:** When touching a component for any reason, replace hardcoded strings with `t()` calls. No mass find-replace — translate incrementally.

## Adding New Languages

1. Create `packages/interface/src/locales/{lang}/*.json` files
2. Add entry to `LANGUAGES` array in `LanguageSelector.tsx`

No other code changes needed.
